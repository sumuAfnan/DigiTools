Description

DigiTools Platform is a web application where users can browse and purchase digital tools. The platform allows users to view products, add them to the cart, and see a dynamic cart count in the navbar. It is fully responsive and designed based on Figma wireframes.

Technologies Used
React.js – For building the frontend UI.
Tailwind CSS & DaisyUI – For styling and responsive design.
JavaScript (ES6+) – Application logic.
React-Toastify – For notification messages (add to cart, remove, checkout).

JSON – To store product data.
Features
Product Display – Products are shown in a 3-column layout with details like name, description, price, period, tag, features, and icon.
Cart Functionality – Add products to the cart, view total price, and remove items individually or via "Proceed to Checkout".
Responsive Design – Works smoothly across all devices (mobile, tablet, desktop).
Optional Features Implemented
Dynamic cart count in the navbar updates when products are added or removed.
“Buy Now” button shows a toast message when a product is added to the cart.
